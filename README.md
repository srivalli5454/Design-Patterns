# Java Design Patterns

This repository contains implementations of three software design patterns in Java.

## Singleton Pattern
Ensures that a class has only one instance and provides a global access point to it.

## Bridge Pattern
Separates an abstraction from its implementation so both can vary independently.

## Adapter Pattern
Allows incompatible interfaces to work together through an adapter.
